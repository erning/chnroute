# IPv6 addresses that are not ordinary globally reachable destinations.
# Unique-local addresses are intentionally excluded.
#
# Rules are applied from top to bottom. A CIDR adds addresses to the set.
# A rule prefixed with ! removes addresses from the set.
#
# Sources:
# - RFC 4291 IPv6 addressing architecture.
# - RFC 6890 special-purpose address registries.
# - IANA IPv6 Special-Purpose Address Space, updated 2025-10-09.
#
# Policy:
# - 2000::/3 is treated as the potential global-unicast address space.
# - Special-purpose prefixes are included unless IANA marks them globally
#   reachable.
# - N/A and deprecated global-reachability entries are included.

# Begin with all IPv6 addresses, then remove potential global unicast and
# unique-local private space.
::/0
!2000::/3
!fc00::/7

# Globally reachable IPv4-IPv6 translation prefix outside 2000::/3.
!64:ff9b::/96

# IETF protocol assignments inside global unicast. More-specific entries
# marked globally reachable by IANA are removed from this set.
2001::/23
!2001:1::1/128
!2001:1::2/128
!2001:1::3/128
!2001:3::/32
!2001:4:112::/48
!2001:20::/28
!2001:30::/28
